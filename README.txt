모둠 — GitHub Pages 배포 안내

1. GitHub에서 새 공개 저장소를 만듭니다. 예: team-balance
2. 이 ZIP을 압축 해제합니다.
3. 저장소의 Add file → Upload files에서 index.html과 app.js를 함께 업로드합니다.
   두 파일은 폴더 안이 아닌 저장소의 최상위에 있어야 합니다.
4. Commit changes로 저장합니다.
5. Settings → Pages → Build and deployment로 이동합니다.
6. Source를 Deploy from a branch로 선택합니다.
7. Branch는 main, 폴더는 / (root)를 선택하고 Save를 누릅니다.
8. 배포가 완료되면 Pages 설정에 표시되는 주소를 엽니다.
   일반적인 주소 형식: https://사용자명.github.io/team-balance/

업데이트할 때는 변경된 파일을 같은 위치에 다시 업로드하고 커밋합니다.
별도 설치나 빌드가 필요 없는 HTML과 JavaScript 웹앱입니다.
학생 정보는 서버로 전송되거나 자동 저장되지 않습니다.
새로고침하면 명단이 초기화됩니다. 결과는 CSV로 저장할 수 있습니다.
공개 저장소에는 실제 학생 명단이나 성적을 올리지 마세요.
